# План: CatBoost для предсказания SI VACV

## Цель

Обучить `CatBoostRegressor`, который по SMILES предсказывает `SI VACV`, и
систематически уменьшать MSE. Целевая метрика измеряется в миллионах, поэтому
сырой MSE чувствителен к выбросам; отчёт ведём и на сыром SI, и на `log1p(SI)`.

## Данные

- `data/dataset.csv` — 320 строк организаторов (+ 26 строк ChEMBL собираются
  отдельно в `data/dataset_chembl.csv`).
- `data/organizers/train.csv`, `test.csv` (597), `sample_submit.csv`.
- Целевая колонка: `SI VACV`. Точные строки: `SI_lower == SI_upper`;
  81 строка с потолком `SI VACV = 10000` имеет `SI_upper = inf`.

## Решения

1. Метрика: MSE/RMSE на `SI VACV`; дополнительно на `log1p(SI)`.
2. Базовое обучение — на точных строках; потолок подключается отдельным
   экспериментом.
3. Таргет: `log1p(SI)` по умолчанию (стабильнее), `--target raw` для
   оптимизации сырого MSE.
4. Признаки — только структура: Morgan (radius 2, 2048, counts) + дескрипторы
   RDKit. `CC50_uM` и `IC50_uM_VACV` в признаки не попадают никогда.
5. Разбиение — групповое (scaffold или SMILES), чтобы исключить утечку.

## Шаги

1. `src/features.py`: `featurize(SMILES) -> np.ndarray`, матрица признаков.
2. `src/split.py`: групповые фолды, `splits.csv`.
3. `src/train.py`: CatBoost, OOF-метрики, параллельное обучение фолдов,
   сохранение моделей и `oof.csv`.
4. `src/predict.py`: `predict(smiles)`, сборка `submission.csv`.
5. `Makefile`: `train`, `submit`.
6. Эксперименты: Dummy → CatBoost(exact) → CatBoost(+cap) → raw/log →
   гиперпараметры → +ChEMBL.

## Параллелизм

- Фолды обучаются параллельно (`ProcessPoolExecutor`), число процессов —
  `--jobs` (по умолчанию `min(folds, cpu_count)`).
- Внутри процесса `thread_count = cpu_count // jobs`, чтобы не перегружать
  машину.
- `--jobs 1` — последовательный режим для отладки.

## Критерии готовности

- [ ] `make train` воспроизводит OOF-метрики (seed, конфиг).
- [ ] Признаки только из SMILES; утечки нет.
- [ ] Групповой split; одинаковые SMILES не попадают в разные фолды.
- [ ] `make submit` пишет `index, SI VACV` для 597 строк.
- [ ] MSE в миллионах зафиксирован и сравнивается между экспериментами.

## Подводные камни

- Потолок 10000 — нижняя граница, а не точное значение.
- `SI = 0` ломает `log10`; используем `log1p`.
- В `test.csv` 468/597 строк содержат CC50/IC50; их нельзя использовать.
- 42 дубля Title в train, 51 Title и 9 SMILES общих с test.

## Результаты

320 строк организаторов, 5-фолдовый OOF.

| Модель | Сплит | OOF MSE(SI) | RMSE(SI) |
|---|---|---|---|
| Dummy (медиана) | — | 29.5M | 5 431 |
| CatBoost raw, все строки | scaffold | 16.6M | 4 074 |
| CatBoost two-stage (классификатор потолка + регрессор), MACCS+scaffold | SMILES | **11.6M** | 3 402 |

Выводы:

- Scaffold-split слишком строгий для этого соревнования: у организаторов
  train/test не разнесены по каркасам (есть общие SMILES/Title), поэтому
  оценка на scaffold занижает модель. Для подбора модели используем
  групповой split по SMILES.
- Основной вклад в MSE дают строки с потолком SI=10000 (81 шт.). Их надо
  распознавать отдельно: классификатор «capped/высокий SI» + регрессор на
  точных строках, итог `p·10000 + (1−p)·reg`.
- AUC классификатора потолка ~0.93 (random split), ~0.85 (scaffold).

Дальше: калибровка классификатора, больше внешних данных (ChEMBL), подбор
порога/весов бленда, ансамбль по сидам.
