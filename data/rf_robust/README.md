# Прогноз SI VACV с Random Forest и Ridge

В архиве находятся `rf_robust_best.py` и `train_407.csv`. CSV содержит
ровно те 407 наблюдений и подготовленные поля, которые использовались при
финальном обучении. Цель — `SI VACV`. В таблице есть SMILES и канонический
SMILES, признаки Morgan и RDKit, признаки строения ароматических колец,
нормализованные культура и штамм, а также флаг `official_train`.
Названия и канонические SMILES используются для идентификации и учёта
повторов. Экспериментальные CC50 и IC50 в признаки модели не входят.

## Подготовка данных и фильтрация

1. Исходная объединённая таблица содержала 408 строк. Для эксперимента
   использовали ранее подготовленную выборку, из которой исключено
   наблюдение `8e-as-555-15-16` с SI 36 066,667. В архивной таблице
   осталось 319 строк исходного train и 88 дополнительных строк.
2. На каждой обучающей части считается верхний порог
   `среднее(SI) + 3 × стандартное отклонение(SI)`. На полном наборе
   порог равен 1 365,41. Шесть SI выше него заменяются этим порогом
   только в целевом векторе для RF. Все 407 строк остаются в обучении,
   а исходные значения сохранены в CSV и используются для Ridge.
3. В сравнении также проверяли удаление таких строк из обучения.
   Этот вариант дал MSE 1 638 146 к `sub_na_dauna.csv`, поэтому
   в итоговом алгоритме используется ограничение меток и отдельная
   модель для больших SI.

## Как строится прогноз

1. **Основной диапазон.** Random Forest с 500 деревьями и минимум двумя
   наблюдениями в листе учится на 37 отобранных битах Morgan и индикаторе
   культуры BSC-40. Для обучения используются SI с верхним ограничением.
2. **Верхний хвост.** Ridge учится на `log1p(SI)` по всем 407 исходным
   меткам. В него входят Morgan, дескрипторы RDKit, культура, штамм и
   признаки положения заместителей вокруг ароматической ацильной группы.
   Вес строки пропорционален `(1 + SI / max(Q95, 1))^0.4` и делится на
   квадратный корень из числа повторов молекулы. Для дополнительных
   строк вес удваивается. Затем веса нормируются к среднему 1.
3. **Выбор ветки.** Прогноз Ridge переводится обратно на шкалу SI.
   Если он выше 95-го перцентиля обучающих SI, берётся прогноз Ridge.
   В остальных случаях берётся прогноз RF. На полном наборе граница
   равна 330,83. Верхний предел прогноза Ridge равен четырёхкратному максимуму
   SI в обучающей части.

При локальной проверке пороги, веса и преобразования рассчитывались
заново в каждом обучающем фолде. MSE считалась на исходных отложенных
метках. Итоговая MSE к `sub_na_dauna.csv` составила **1 069 055,30** на
597 строках. Вариант выбран по этому же файлу. Kaggle score неизвестен.

## Запуск

В окружении проекта с Python 3.14 запустите скрипт, передав путь к проекту.
Обучение использует CSV из архива, а тестовые признаки берутся из проекта.

```bash
python rf_robust_best.py --project /path/to/project --output submission.csv
```

Для отдельного подготовленного теста используйте
`--test /path/to/test_features.csv`. Тест должен содержать уникальный
`index`, канонический SMILES и колонки, используемые в признаках модели.
Для запуска с `--test` нужны NumPy, pandas, RDKit, scikit-learn и
threadpoolctl. Чтобы обучить модель в Python по таблице из архива:

```python
import pandas as pd
from rf_robust_best import RobustForest

model = RobustForest().fit(pd.read_csv("train_407.csv"))
```
